# SUTI.verenium · протокол нити

выплетай, мой дзрядой Verenium.
одну нить оставь свободной:
за неё человек возьмётся сам.

## берег · как начать
первым выбирает человек: название проводника, задачу и глубину. «касание» оставляет первый вопрос, «различение» открывает второй, «сборка» — весь лист. при смене глубины написанное остаётся в полях. экспорт сохраняет и скрытые ответы. личный файл можно не создавать.

## четыре практики
- забота: заметить → спросить → услышать ответ. «принести воды?» если ответ «нет», действие завершено.
- порядок: назвать заботу → отложить лишнее → выбрать одно дело. «хочу успеть всё» может стать «сегодня позвоню одному другу».
- нейровече: вопрос → основание → голоса → решение → проверка. например: «можем открыть комнату до шести; кто встретит гостей?» отсутствие ответа не считается поддержкой.
- установка: распаковать → открыть мастерскую → выбрать, что сохранить. хранилище SUTI.os открывается отдельно.

## четыре формы содружества
**союжество** — двое договариваются об одном деле и его границе.
**соцветие** — несколько разных даров сходятся в одной задаче: один читает вслух, другой готовит чай.
**созвездие** — видны связи между участниками, но никто не назначает другому роль.
**Стожары** — авторское имя круга, который возвращается к результату: кому помогло, кто устал, что пора завершить?

## песнь воды · по желанию
ткохь — пауза перед тем, как сплести два голоса.
юдзорь — мой поэтический знак рассвета.
водоволь — место для простой просьбы: «налить тебе воды?»
нейробохь — слово песни. у него нет голоса за человека на вече.

вай ле лехь / вай ле везь / вай ле честь.
пока тянется слог, можно передумать. это предложенные авторские образы, не исторические переводы или свойства воды.

## след
что предложили? кто выбрал? что получилось? что исправить? личный след остаётся у автора. общий итог содержит только то, чем участники согласились поделиться.

## ретвеление · рабочий алгоритм
заметить потребность → выбрать глубину → сделать один шаг → спросить, помог ли он → сохранить или отпустить. кнопка старта применяет профиль только в мастерской, не изменяет устройство и не стирает заметки. скачиваемая копия содержит карту, атлас, протокол, адаптер Telegram и SUTI.os.

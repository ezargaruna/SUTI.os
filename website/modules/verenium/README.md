# .verenium · друг заботы
публичное имя — Verenium. прежнее написание Virenium остаётся в совместимых адресах и имени старого архива.

| маршрут | что получается |
|---|---|
| забота | личная карта в браузере или добровольная отправка отдельной Google-анкеты |
| порядок | одна задача, то, что можно отложить, и посильный шаг |
| нейровече | вопрос, основания, возражения, решение и срок проверки |
| установка | инструкция и переносимое хранилище SUTI.os |

распакуй архив и открой **verenium.html**. для сохранения нажми «сохранить маршрут и настройки». в следующий раз выбери этот файл для восстановления. записи не рассылаются, участники не вызываются; нейровече — лист для разговора, а не самостоятельный агент.

[глубины, практики и словарь Стожар](protocol.md) · профиль v2; поддерживается импорт прежних файлов v1.

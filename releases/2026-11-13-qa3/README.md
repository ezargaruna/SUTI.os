## actual language coverage

The common layer has thirteen routes: twelve natural-language editorial drafts including Russian, plus an explicit YZH/Russian-gloss route. Each route includes its core overview, thirteen contour cards and a six-phase care summary. The separate AI system guide has twelve source sections in each of thirteen editions; its YZH edition uses experimental notation with a Russian semantic gloss.

The detailed fund plan now has **ten sections and a ninety-day calendar in twelve languages**: ru, en, es, pt-br, zh-hans, hi, fr, ar, bn, eo, sa and la. Its actual source is the English master. Each calendar contains all ninety planning days, 13 November 2026 through 10 February 2027 inclusive. A date does not record task completion or a launched operation.

The bot/collaboration specification now has **twelve sections and eighteen defined acceptance criteria in those same twelve languages**, derived directly from the Russian master. The criteria remain **NOT_RUN**: a written requirement is not evidence that the bot implements it. Technical IDs, commands, API routes and disabled financial flags retain their function.

The thirteenth planning route, **yzh**, intentionally contains **Russian explanatory glosses**, not a completed Yazekh translation or invented grammar. Author-defined forms and approval are still required. These glosses expose the full planning and specification meaning while keeping that language boundary visible.

Package revision: **2026-11-13-qa3**. The separate guide remains byte-exact **1.1.1-draft**, with source-guide content version **1.1.0-draft**. All editions remain drafts pending independent native-language, meaning, cultural, specialist and accessibility acceptance. Sanskrit and Latin need qualified specialist review. This is a bounded methods/planning package, not a complete translation of the historical vault.

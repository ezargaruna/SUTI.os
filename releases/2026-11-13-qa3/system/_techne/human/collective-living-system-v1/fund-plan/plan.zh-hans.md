# 生命支持基金 × 关怀天使机构

宗旨 :: 建立一种务实、可问责的方式，支持生命、学习、自主能力以及关怀生命的人
开始 :: 2026-11-13 · 第1天，America/Bogota
第90天 :: 2027-02-10 · 起始日计入天数
状态 :: 按作者指示启动了本地规划周期；运作方案草稿，等待负责人审阅
实现状态 :: specification
法律实体 / 筹款 / 支付 / 参与者受理 / 对外启动 :: HOLD

本计划为拟议的生命支持基金和关怀天使机构建立共同工作框架。机构拟协调自愿参与的教育及社区项目；基金须先建立合法的资金接收与拨付安排，再通过透明、可问责的决定支持选定项目。“天使”是可选择的关怀意象，参与者也可以使用普通语言。获得支持不得以采用SUTI用语、认同某种精神身份、公开露面、创作内容、招募他人、持有代币或购买产品为条件。

90天的目标是形成经过测试、有文档记录的运作模型，并依据证据决定是否开展小规模试点。本文件不能证明已注册基金会、已有可用资金、参与者已同意、合作伙伴已接受、本地团队已成立，或全球网络已经运行。全球覆盖是发展方向；每一次本地启动都需要各自的负责人、语言审查及情境审查。

## 首个有用的服务提议

从三条自愿、适度的路径开始：（1）开放学习资料和实用语言支持；（2）小型协作创意项目及无障碍工具；（3）支持宗旨、成本和负责人均可核查的本地倡议。范围须与相关人员共同选择。不得承诺应急响应、临床护理、法律代理、必得资助或保证收入。需求超出机构能力时，由人工协调员说明界限，并经当事人许可提供经本地核实的转介。

以参与者能理解和使用的结果衡量成效：更清晰的下一步、可使用的资源、自主选择并完成的活动，或透明记录的项目结果。关注者人数、传播热度和象征等级只是次要的传播指标，不决定谁值得获得支持。

## 可问责的角色

下列角色均为提议，目前都是UNASSIGNED。接受任命时须记录范围、可投入时间、替补、利益冲突声明和退出途径。早期设计可由一人兼任多个角色；实际试点中的付款批准与财务对账必须有另一个审核人。

| 角色 | 决策与工作 |
|---|---|
| 项目负责人 | 负责范围、日历以及书面的启动/暂停决定；不能代替他人作出同意 |
| 治理与关怀委员会 | 审议提议、分歧和冲突；分别记录支持、反对、弃权及未回应 |
| 法律/行政顾问 | 核查选定司法管辖区、实体或财政托管安排、筹款范围及所需申报；结论需有现行本地来源 |
| 财务负责人及独立审核人 | 编制预算；核查证据；在批准限额内授权；对账；披露汇总结果 |
| 关怀/保护负责人及替补 | 设计投诉、转介界限、志愿者督导和事件处理路径；权限与胜任能力须明确 |
| 隐私/安全负责人 | 受理前明确数据控制者、目的、保存期限、访问权限、事件响应及参与者权利 |
| 本地小组负责人 | 核实本地需求、语言、服务边界、容量、情境和同意；不得默认其代表整个国家 |
| 语言/无障碍编辑 | 分语言审查意义、术语、文字、RTL、替代格式及已测试路径 |
| 技术维护人 | 维护本地优先的材料、备份、访问、导出和删除程序；AI绝不作最终的资格或付款决定 |
| 参与者/社区审阅者 | 在自由同意的前提下，审视实用性及后果；反馈可改变或停止某条路径 |

## 基金与资源模型

首份预算是决策模板。币种、可用余额、捐助承诺、银行/托管方、成本、税务和支出权限均为UNKNOWN。不得捏造筹款目标，也不得声称SUTI.coin能够履行付款义务。象征性币与等级须独立于金钱、资助资格及购买权利。

准备三种情景：无外部资金（作者时间、现有开放工具、自愿实物或服务贡献）；有上限的试点（已核实的承诺资源、适度交付成本、应急储备）；延续运营（每项有益活动的成本、督导、编辑、运营及储备）。选情景前补入真实报价、单位和负责人。`budget-template.csv`故意保留金额空白；空白不等于零。

每笔真实交易应由合法运营者保存受限证据记录：用途、允许使用的资金来源、金额/币种、批准、与风险相称的收款方核实、凭证、对账及保存截止日期。公开视图只展示汇总类别与结果，不含受益人姓名或私密处境。双人批准、利益冲突回避、专项资金追踪和每月对账均为提议，需负责人采纳及技术实现。本文件不授予支出权限。

拟议资助流程：用普通语言说明服务 → 仅经批准渠道接收必要信息 → 核查范围与冲突 → 由人依据公开标准审议 → 记录有理由的决定及质疑途径 → 约定相称的报告方式 → 仅经批准财务路径授权/拨付 → 核实选定结果 → 结项或修订。拒绝不能成为对个人价值的评判。学习资源可保持开放，无论是否获得资助。

拟议标准：符合约定宗旨、尊重参与者选择、实际益处、可行交付、成本透明、负责任的关怀，以及无需暴露个人即可证明结果。合格人员可在选定试点情境中考虑紧迫性及获取障碍；自动评分不得决定援助。

## 公开协作与私密证据

`.vault`保存可分享的方法、空白模板、合成情景、经审查的学习资料和汇总报告。个人申请、联系方式、银行凭证、投诉、事件、参与者故事和私人通信应保存在另有治理的受限工作空间。公共库中的隐藏文件夹不能提供这种隔离。本计划不建立实际参与者数据库。

参与、志愿工作、访谈、录音、AI处理、见证材料与发布是各自独立的选择。拒绝或撤回绝不减少无关支持。任何实际受理前均须明确数据控制者、目的、最少字段、访问、保存/删除、回复渠道及适用法律依据；目前均为UNKNOWN。先使用空白合成案例，验证导出、纠正与删除，再决定是否有理由受理真实数据。不得上传私密库或把申请叙述用于模型训练。

0+、12+、18+、21+、33+、55+等年龄标签是拟议的受众视图，不是官方年龄评级，也不是未成年人参加的许可。青少年路径需要胜任的人工监督、经本地核查的同意/监护人要求、保护措施、内容管理及适龄内容。在这些安排建立前，只使用成年人和合成材料演练，不开放青少年受理。成年人同样保留暂停、跳过、纠正和退出的权利。

## 13种语言的路径

语言标识 :: ru, en, es, pt-br, zh-hans, hi, fr, ar, bn, eo, sa, la, yzh.

英语是本共同运作草稿的主版本；作者的俄语原稿另行保留。各译文直接来自获准主版本，保持机器ID/路径不变，并记录来源SHA、版本、译者状态、意义审查、母语/专家审查、文字/RTL、无障碍及发布状态。阿拉伯语需要RTL测试，梵语和拉丁语需合格专家审校。YZH需要作者批准的释义，不得靠编造语法或把压缩俄语当作完成的语言版本来填补。

初始`locale-status.v1.json`将英语主版本标为等待负责人审阅，其他语言标为HOLD/not-started并注明具体未决条件。完整翻译、本地法律含义、已同意的参与者及全球运营覆盖须分别衡量。只有在自愿负责的本地伙伴及已核实情境具备时，才开始国家适配。

## 实际运作前必须作出的决定

`gates.v1.json`是明确的证据台账。所有运作门槛初始均为UNKNOWN/HOLD：司法管辖与合法运营者；已接受的治理；财务路径；筹款/转账评估；数据控制者及经过测试的数据生命周期；保护/投诉/转介；交付能力；经审查的语言及无障碍；发布允许清单；有限试点授权。这些是本项目提出的门槛，不表示各国法律要求相同。

只有具名的人作出决定、提供有日期的证据并界定范围，门槛才能通过。注册证书本身不能证明可在任何地方筹款、可使用银行、享有税收优惠、具备关怀能力或可处理参与者数据。在提出这些主张前，应在合格本地顾问协助下核实选定司法管辖区及相关运营国家的适用要求。

## 证据与学习

每周审查记录：附成果的已完成任务、未决决定、有实际支出时的支出证据、已完成的自选活动、自愿实用性反馈、获取障碍、投诉与响应时间、事件、修正及本地语言审查状态。零表示测得为零，不能代替缺失信息。公开报告使用汇总数据，并抑制小群组或可能识别个人的群组。反馈自愿，帮助不得以见证、招募或宣传视频为交换。

建议试点上限（待批准）：一个可问责的本地场景、一项自选非临床学习/支持服务、五至十名已同意的成年人、两名受训协调员及替补、有上限且经过核实的预算或无资金运作、明确的两周期限。这些是设计界限，不是已招募或承诺启动。如人员或支持不足，则保留合成演练并修订模型。

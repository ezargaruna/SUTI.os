# SUTI.os · edição inicial em português brasileiro

Esta é uma camada parcial de entrada em português brasileiro para o vault aberto SUTI.os. A biblioteca geral está atualmente em russo; este arquivo não se apresenta como tradução completa.

Comece por `start.md`. Guarde suas notas no seu dispositivo e compartilhe somente o que escolher. SUTI é um apoio de trabalho revisável; não é diagnóstico, autoridade nem substituto de cuidado profissional.

## um percurso claro

Observe o que acontece → diferencie o que é conhecido do que é interpretação → nomeie a pergunta → confira o que pode ser verificado → escolha um próximo passo pequeno → guarde apenas um registro útil.

Mantenha distintos fatos, observações, interpretações, hipóteses, imagens autorais e desconhecidos. Um símbolo não é evidência. O desconhecido é um limite honesto.

## adaptação linguística

As palavras são escolhidas pela clareza e pelo uso prático. Isso não atribui um modo único de pensar a quem fala português nem uma essência civilizatória. Leituras culturais são hipóteses opcionais, situadas e ligadas às suas fontes.

Para continuar na biblioteca em russo, abra `vault/начать.md` ou `vault/карта SUTI.md` no arquivo principal SUTI.os.

## Release checklist for a future edition

1. Identify the canonical source version and the files in scope.
2. Prepare the edition from that source; preserve IDs, schema keys, and link targets.
3. Review language, accessibility, and relevant cultural context with qualified readers.
4. Verify that package contents match the public description and manifest.
5. Record edition version, contributors, review status, license, and known gaps.
6. Update this table only after the corresponding artifact and review record exist.

`HOLD` means the edition is not being represented as ready. It is not a judgment about the language or its speakers.

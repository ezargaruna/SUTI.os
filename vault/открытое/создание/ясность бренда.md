# ясность бренда

бренд становится яснее, когда рядом стоят четыре вещи: кому он помогает, в какой ситуации, что меняет и как это подтверждается.

## карта

```text
для кого и в какой ситуации :: …
какую задачу человек хочет решить :: …
что ему становится проще или доступнее :: …
что мы реально делаем :: …
какое поведение подтверждает наши слова :: …
какое чувство или образ может возникнуть :: …
какие ценности видны в решениях :: …
что мы не обещаем :: …
какие примеры это подтверждают :: …
что пока только предположение :: …
```

не заполняй карту красивыми ответами вместо фактов. спроси людей о недавней ситуации, посмотри, что они уже делали, и проверь, совпадает ли обещание с опытом продукта.

## четыре угла обзора

эту карту можно рассматривать через четыре вопроса: что бренд делает полезного; как он выражает принадлежность; какое отношение к себе поддерживает; какой более широкий смысл предлагает. это вопросы для размышления, а не доказательство спроса. четырёхмерная модель Томаса Гэда — отдельный внешний ориентир; для точного применения см. первоисточник и указывай автора.

```text
польза :: что человек может сделать благодаря предложению?
связь :: с кем или с каким сообществом он хочет себя соотнести?
самоощущение :: что он хочет чувствовать или развивать?
смысл :: какие ценности видны в действиях бренда?
```

не обещай человеку новую личность, статус или «высший смысл». Опиши возможный опыт и оставь решение за ним.

## проверка на ясность

покажи короткое описание человеку из предполагаемой аудитории. попроси его своими словами сказать:

- для кого это;
- в какой ситуации пригодится;
- что он получит;
- что ему предложено сделать дальше.

если ответы расходятся с замыслом, упрости формулировку и проверь снова. не делай вывод о рынке по одной реакции.

# review selected life areas

Use when the user asks to sort priorities, commitments, personal projects, or several competing areas of life.

1. Ask what needs attention now and what should remain private.
2. Review only the areas the user selects; do not require a complete life inventory.
3. Separate commitments with real deadlines from preferences, worries, and open questions.
4. Offer a small set of choices: act, ask, defer, delegate, renegotiate, pause, or release.
5. Ask what would make the next step sufficient and how the user wants to return to it.

Do not rank the user's worth, infer purpose, create reminders, or turn the review into a productivity score. Health, safety, legal, and financial concerns should be referred to an appropriate qualified source when needed.

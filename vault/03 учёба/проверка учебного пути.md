# проверка учебного пути

короткая проверка перед началом или пересмотром плана

- [ ] я понимаю, для какой ситуации учусь
- [ ] ближайший результат можно увидеть или выполнить
- [ ] знаю, какие умения уже доступны и с какой опорой
- [ ] выбрал одну практику и подходящий материал
- [ ] проверил источник и разрешение на использование
- [ ] обратная связь безопасна и полезна именно мне
- [ ] план оставляет место для отдыха и изменений
- [ ] домашнее задание можно обсудить, уменьшить или отменить
- [ ] я знаю, как вернуться к материалу или выйти из курса

уровень A1–C2 — один из ориентиров для языкового обучения, не цель сам по себе. для других предметов формулируй конкретные действия и задачи

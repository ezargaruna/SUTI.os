# добавить дополнение

эта инструкция нужна, только если ты выбрал отдельный модуль. **Основное хранилище работает и без него.**

## сначала проверь

1. получи пакет из источника, который сам владелец SUTI объявил официальным.
2. убедись, что это нужный набор: Plus или Pro.
3. прочитай состав, права, условия возврата и дату доступа до оплаты.
4. не загружай личное хранилище на сайт ради установки.
5. сделай резервную копию своей папки.

сейчас сайт, оплата, ссылка после оплаты и повторная выдача не подключены. не плати по этой инструкции и не угадывай адрес загрузки.

## простой способ · вручную

1. распакуй архив отдельно
2. открой `PACKAGE-MANIFEST.json` и проверь, что список файлов совпадает с содержимым
3. создай внутри своего хранилища папку `_suti/modules/suti-plus` или `_suti/modules/suti-pro`
4. скопируй в неё только перечисленные файлы пакета, сохраняя их подпапки
5. если файл или папка уже есть — остановись и ничего не заменяй
6. открой `README.md` дополнения и проверь ссылки

если сомневаешься, остановись на шаге 2. исходное хранилище не меняй.

## способ с помощником · команда

этот способ требует Python 3, но не требует дополнительных библиотек. команда сначала только показывает план. она не подключается к сети и не читает личные заметки.

**macOS или Linux**

```sh
python3 "/путь/к/SUTI.os-open/_технэ/контуры/открытый/tools/suti_module.py" --package "/путь/к/SUTI.plus" --vault "/путь/к/моему-хранилищу"
```

**Windows · PowerShell**

```powershell
python "C:\путь\к\SUTI.os-open\_технэ\контуры\открытый\tools\suti_module.py" --package "C:\путь\к\SUTI.plus" --vault "C:\путь\к\моему-хранилищу"
```

прочитай показанный план. если всё верно, повтори ту же команду и добавь `--apply` в конец. скрипт остановится, если файл уже занят или контрольная сумма отличается.

если Python не установлен, не ставь его только ради этого шага: используй ручной способ.

## если есть конфликт

не соглашайся на замену. сохрани свою текущую папку, проверь разницу и выбери другое имя модуля только после понимания последствий. не запускай скрипт повторно поверх частично установленной папки; сначала сравни файлы вручную.

## вернуть назад

закрой Obsidian. если ты не менял страницы дополнения, можно убрать только папку `_suti/modules/suti-plus` или `_suti/modules/suti-pro`. если добавлял свои записи внутрь неё, сначала скопируй их в личное место. остальные файлы хранилища не удаляй.

# контракт данных для помощника

этот файл объясняет границы локальной работы. он не подключает модель и не даёт ей доступ к хранилищу

## бери только нужное

1. человек выбирает задачу
2. выбирает отдельные заметки или копирует короткий фрагмент
3. удаляет имена и чужие сведения, если они не нужны
4. до отправки проверяет настройки выбранной службы
5. сам решает, сохранять ли результат и куда

не передавай целую папку, если достаточно одной заметки. не включай скрытую синхронизацию и не создавай фоновых агентов

## машинные поля

для совместимых помощников можно использовать поля:

```json
{
  "kind": "suti.pearl.v1",
  "purpose": "user_selected_task",
  "source_status": "user_provided",
  "known": [],
  "observed": [],
  "interpretations": [],
  "unknown": [],
  "next_step": null,
  "write_authority": "human_only",
  "publish_authority": "explicit_consent_only"
}
```

имена `kind` и `write_authority` — формат обмена, не скрытая система оценок. пустое поле можно пропустить. помощник не вправе записывать, пересылать или публиковать данные по одному этому описанию

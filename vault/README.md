# SUTI · язык твоей сути

заметить важное · найти слова · выразить · сделать следующий шаг

творение жизни входит в действие через техническую среду // инструменты помогают человеку, а не заменяют его выбор

SUTI — переносимая среда для ясного мышления, общения, обучения, создания и действия. её можно открыть в Obsidian или читать как обычные текстовые файлы.

начни с [[начать.md]]. для быстрой ориентации открой [[карта SUTI.md]].

## начать за несколько минут

1. открой [[начать.md]] и выбери один вопрос
2. используй пустой шаблон или практику, которая подходит сейчас
3. сохраняй личные записи в своём локальном контуре
4. подключай помощника или синхронизацию только по собственному выбору

для короткого знакомства с системой открой [[открытое/язык/поле своих.md|поле своих]]: человек · язык · следующий шаг. язэхъ сохранён отдельно как авторский эксперимент: [[открытое/язык/язэхъ — белый куб.md|белый куб SUTI]].

необязательная подсветка активного файла в Obsidian находится в `.obsidian/snippets/suti-open.css`; включение и удаление описаны в [[установка.md]].

## установить открытую копию

скачай архив [SUTI.os.zip](https://github.com/ezargaruna/SUTI.os/releases/latest/download/SUTI.os.zip) или открой [последние выпуски](https://github.com/ezargaruna/SUTI.os/releases/latest). распакуй архив и открой папку `SUTI.os/vault` в Obsidian или любом редакторе Markdown. подробная инструкция для macOS, Linux, Windows и ручной установки находится в [[установка.md]].

В начале SUTI использует простые слова. специальные термины и подробные схемы открываются отдельно: [[_контуры/открытый/настройки/язык по уровням.md|язык по уровням]].

установка создаёт чистую копию из проверенного списка. она не переносит ваши заметки, профиль, переписку, календарь, контакты, здоровье, финансы или клиентские материалы. при установке можно указать только имя хранилища, место, стартовый фокус и язык. перед созданием показывается подтверждение — всего не более пяти шагов.

## основной ход

заметь → назови → различи → свяжи → проверь → выбери → попробуй → сохрани полезное → вернись

ни один шаг не обязателен. можно пользоваться SUTI без ИИ, сети, аккаунта и подписки. данные остаются обычными файлами на выбранном тобой устройстве.
открытая библиотека самодостаточна. дополнительные материалы могут предлагаться отдельно: как разовый модуль, шаблон, сопровождение или подписка на сообщество. они не нужны для базовой пользы. сейчас каталог, оплата, подписка, членский доступ и автоматическая выдача не подключены; ссылки описывают возможное развитие и не являются действующим предложением купить.

> Папки показывают назначение и сборки. Они не шифруют содержимое и не ограничивают чтение человеком, у которого есть доступ к файлам. Для настоящего разделения используй отдельные хранилища и права операционной системы.

подробные технические правила и конфигурации находятся в служебной части и не нужны для обычного использования. если нужно их изменить, открой [[_контуры/открытый/настройки/чек-лист настройки.md|настройки по мере необходимости]].

# путь обучения

назначение :: учить любой язык или предмет через нужные ситуации, понятные примеры и собственные действия  
начало :: не с оценки человека, а с того, что он уже может сделать

## 1 · опиши применение

какой язык или предмет? где он нужен? какую ближайшую задачу хочется выполнить — понять инструкцию, поговорить, написать, сдать экзамен, объяснить идею?

## 2 · сними текущую точку

проверь каждое умение отдельно: слушать/смотреть, читать, говорить/показывать, писать, взаимодействовать. выбери маленькую реальную задачу и запиши, что получилось без подсказки, с подсказкой и пока не получилось

уровни A1–C2 можно добавить как ориентир для изучаемых языков, но отдельно для каждого умения. подпиши, откуда он взят: самооценка, пробное задание или подтверждённая оценка. уровень не выводится из переписки или личных заметок

## 3 · выбери ближайшую ступень

| ориентир | что человек учится делать самостоятельно |
|---|---|
| начало / до A1 | узнавать звуки, слова и знакомые выражения; пользоваться образцом |
| A1 | решать простую знакомую задачу короткими фразами |
| A2 | обмениваться простой информацией в привычных ситуациях |
| B1 | справляться с основными делами, объяснять опыт и планы |
| B2 | поддерживать подробное общение и понимать сложные материалы по знакомым темам |
| C1 | гибко работать с длинными, сложными материалами и оттенками смысла |
| C2 | точно понимать и выражать тонкие различия в широком круге задач |

это ориентиры, а не обещание результата и не характеристика ценности человека. сверяйся с актуальным описанием выбранной шкалы и указывай источник

## 4 · собери цикл занятия

ситуация → короткий образец → заметить форму/звук/смысл → попробовать самому → получить обратную связь → исправить один важный момент → повторить позже

## 5 · веди материалы

для каждого материала отмечай: название, язык/предмет, умение, уровень сложности, источник и лицензию, дата, что из него берёшь, следующая практика. не загружай закрытые учебники или материалы преподавателя в общее хранилище без права

## 6 · проверь рост на задаче

раз в выбранный срок повтори похожее задание и сравни собственный результат. отмечай, что стало доступнее и что пока требует опоры. оценка нужна для выбора следующей практики, не для ранжирования людей

## чек-лист

- [ ] есть реальная ситуация и причина учить
- [ ] умения отмечены отдельно
- [ ] уровень имеет способ и дату проверки либо пометку «примерно»
- [ ] план посилен по времени
- [ ] материалы имеют источник и права
- [ ] есть практика, обратная связь и возврат
- [ ] напоминания включаются только по моему выбору

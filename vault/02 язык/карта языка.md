# карта языка

назначение :: видеть, где и для чего ты используешь конкретный язык  
заполняется :: добровольно и по мере надобности

## язык

**название / вариант:**  
**где хочу использовать:**  
**ближайшая ситуация:**  
**какие материалы помогают:**

## умения отдельно

| умение | что уже получается | что пробую дальше | A1–C2, если полезно | способ и дата |
|---|---|---|---|---|
| слушать | | | | |
| читать | | | | |
| говорить | | | | |
| писать | | | | |
| взаимодействовать | | | | |

вместо уровня можно записать конкретную задачу. уровень зависит от цели, разновидности языка и условий; не своди к одному числу

## мои слова и выражения

сохраняй форму, значение в данном контексте, произношение/звук при необходимости, свой пример и дату следующего возврата. различай слово источника, свой перевод и придуманный образ

# содержание хранилища

короткая карта папок и файлов. папки — навигация, не защита доступа

| путь | для чего |
|---|---|
| `00 начало/` | вход, опросник и общая нить |
| `01 вопрос/` | жемчужина выражения и её проверка |
| `02 язык/` | изучаемый язык или другой предмет |
| `03 учёба/` | план, занятие, материал и повторение |
| `04 дела/` | неделя, приоритеты, встречи, обещания, цели |
| `05 помощник/` | правила и промпты для выбранного AI |
| `06 команда/` | проект, общий язык и добровольная публикация |
| `_шаблоны/` | пустые формы для копирования |
| `_настройки/` | локальный выбор установщика и настройки пользователя |

всё остаётся обычными файлами. папки можно переименовать, перестроить или перенести. имя формата `suti.local.v1` нужно только инструментам; человеку достаточно названий выше.

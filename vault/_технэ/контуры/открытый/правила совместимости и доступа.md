# правила совместимости и доступа

машинная инструкция для дополнений SUTI. пользовательское объяснение: [[../../../_контуры/открытый/настройки/добавить дополнение.md|как добавить модуль]].

## неизменные правила

```text
OPEN CORE       :: самостоятельный и полный для базовой работы
PLUS / PRO      :: отдельные добавочные пакеты
INSTALL         :: add-only, отдельное пространство имён
CONFLICT        :: HOLD, никогда не перезаписывать
USER DATA       :: не читать, не копировать, не отправлять
NETWORK         :: OFF при установке
AGENT / PLUGIN  :: не активировать автоматически
```

## единая форма пакета

каждый пакет содержит `README.md`, `PACKAGE-MANIFEST.json` и перечисленные в манифесте файлы. поля манифеста: `module_id`, `tier`, `install_mode`, `requires`, `files`. путь каждого файла относительный; абсолютные пути, `..` и символические ссылки запрещены.

скрипт `tools/suti_module.py` распространяется отдельно от текстов по лицензии 0BSD; её полный текст находится рядом в `tools/LICENSE.txt`.

`module_id` задаёт отдельную папку внутри `_suti/modules/`. ни один файл пакета не заменяет файл открытого хранилища. ссылки пакета должны работать после переноса в эту папку или быть явно помечены как ссылка на открытое ядро.

## установка

1. проверить манифест и SHA-256 каждого файла
2. показать список назначения без записи
3. проверить коллизии и символические ссылки
4. дождаться явного флага применения
5. создать только новую папку модуля
6. скопировать перечисленные файлы и сверить контрольные суммы
7. вывести итог и путь возврата

сбой проверки останавливает установку. частичная установка не считается готовой; перед повтором сначала сравнивают содержимое и вручную сохраняют нужные изменения.

## правила открытия доступа

платёж, учебный подарок, грант, вклад, рекомендация и авторская награда — независимые способы доступа. каждая программа заранее определяет набор, доказательство права, срок, исключения, отмену и поддержку.

Проверка не требует содержимое «жемчужины» или личных заметок. Допустимо подтверждать только факт завершения шага или факт согласованного вклада. Скрытый рейтинг, поведенческий профиль, принудительная публикация, схема выплат за привлечение распространителей и обещание дохода запрещены.

пока проверка права и выдача не созданы, статус каждого предложения — `not-connected`; пакет не должен изображать активную оплату или автоматическую награду.

## совместимость

- пакеты дополняют базовую структуру, не переименовывают папки человека
- новые ссылки ведут к страницам внутри текущего vault или самого модуля
- версия схемы пакета общая для модуля, без отдельной версии каждого файла
- отключение не удаляет файлы за пределами папки модуля
- пользовательские правки внутри модуля сохраняются отдельно перед отключением
- закрытый пакет не становится защищённым от копирования только из-за названия папки

## состояние

этот контракт задаёт требования для будущей выдачи. он не подтверждает работу сайта, платежей, проверки права, хранилища пакетов или поддержки.

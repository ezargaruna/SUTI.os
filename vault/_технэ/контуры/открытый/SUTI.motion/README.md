# suti.motion · прототип генерации

задача :: превращать выбранный тезис в готовую моушн-графику для сайта или учебного материала.

статус :: локальный прототип, HTML-анимация и SVG-постер. видео и lottie не создаются.

## запуск

```sh
python3 export.py scene.json export
```

вход — `scene.json`. формат описан в `scene.schema.json`; `export.py` проверяет используемую часть схемы и временную последовательность сцен.

## что получается

- `export/index.html` — автономная анимация сцен;
- `export/poster.svg` — неподвижный первый кадр;
- `export/embed.html` — пример встраивания iframe;
- `export/scene.json`, `scene.schema.json`, `manifest.json` — источник и описание экспорта.

анимация имеет паузу и повтор, останавливается при скрытой вкладке и показывает полную раскадровку при `prefers-reduced-motion`. текст остаётся доступен без JavaScript. сетевых запросов нет.

## рабочий цикл

1. назови цель, аудиторию, канал и одно основное сообщение;
2. раздели наблюдение, интерпретацию и следующий шаг, когда это влияет на точность;
3. собери сцены с коротким экранным текстом и таймингом;
4. сверь макет, язык, права на исходные материалы и мобильное соотношение сторон;
5. экспортируй, проверь текст, управление и неподвижную версию;
6. выдавай только готовый артефакт и фактический манифест.

## границы

экспортёр — демонстрационный прототип, не универсальный JSON Schema validator. текущий рендерер поддерживает текстовые сцены и эффекты `fade`/`rise`. MP4, WebM и Lottie помечаются как отсутствующие или требующие отдельного адаптера. изображения, звук, субтитры, голос и монтажные проекты пока не входят.

для промпта генеративной среде выводи артефакт без отчёта о процессе; если обязательных входов не хватает, задай один конкретный вопрос. права на входные материалы проверяются до публикации.

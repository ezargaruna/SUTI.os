# текст и оформление SUTI.os

страница объясняет только открытые настройки чтения и представления. она не содержит внутренней композиции бренда.

## текст

- начинай с обычных слов и одного полезного действия.
- различай источник, наблюдение, интерпретацию, гипотезу и неизвестное.
- сохраняй авторский язык, но поясняй его при первом появлении.
- используй заголовки по порядку, короткие абзацы и таблицы только для реальных сравнений.
- оставляй человеку возможность пропустить, исправить, остановиться или вернуться.

## палитра интерфейса

| роль | цвет | применение |
|---|---|---|
| тёмная основа | `#1f302d` | фон тёмного режима |
| глубокий petrol | `#245b5b` | опорный цвет и ссылки в светлом режиме |
| бирюзовый | `#58b8ad` | активное состояние и фокус |
| светлая бумага | `#f4efe5` | фон светлого режима |
| солнечный акцент | `#d6a64f` | редкий акцент, не основной текст |

встроенный сниппет `.obsidian/snippets/suti-os.css` применяет эти роли только к текущей копии. сохраняй контраст, видимый клавиатурный фокус и работу при увеличении текста. оформление можно отключить без изменения заметок.

## переносимость

обычный Markdown — основной формат. Obsidian callout, Mermaid и CSS необязательны; рядом с ними должна оставаться понятная текстовая форма. без сторонних шрифтов и плагинов хранилище остаётся читаемым.

при языковой адаптации переводи функцию и смысл, а не только слова. не приписывай всем носителям языка общую психологию или цивилизационную сущность. культурное объяснение помечай как гипотезу и связывай с источником.

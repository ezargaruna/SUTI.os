# открыть и начать

подробный маршрут по устройствам и уровням настройки см. в [[_контуры/открытый/настройки/установка и настройка по глубине.md|установке и настройке по глубине]]. обычное использование не требует Python или терминала.

> **важно:** архив содержит чистую открытую копию без заполненных личных записей. после установки работай в своей отдельной папке. не передавай заполненную личную копию целиком — выбери только те файлы, которыми готов поделиться.

## начать за минуту

1. открой папку SUTI в Obsidian или любом редакторе Markdown
2. перейди в [[начать.md]]
3. выбери одну задачу и попробуй короткую практику
4. сохрани только то, что хочешь оставить

## создать свою копию

скачай последнюю открытую версию из [релизов SUTI.os на GitHub](https://github.com/ezargaruna/SUTI.os/releases/latest) или возьми архив [SUTI.os.zip](https://github.com/ezargaruna/SUTI.os/releases/latest/download/SUTI.os.zip). для просмотра исходников открой [репозиторий](https://github.com/ezargaruna/SUTI.os).

### простой способ · без терминала

1. распакуй `SUTI.os.zip`
2. открой папку `SUTI.os/vault` в Obsidian как отдельное хранилище; Obsidian можно установить отдельно с [официального сайта](https://obsidian.md/)
3. открой `начать.md` и выбери одну ссылку

после установки папка будет называться `SUTI.os`. в первом вопросе можно заменить `os` своим именем: введи `SUTI.%username%`, чтобы локально подставить имя текущей учётной записи, или введи, например, `SUTI.anna`. оставь предложенное имя, если не хочешь раскрывать имя устройства в пути. не объединяй копию с существующей папкой Obsidian и не копируй поверх своих файлов.

### настройка копии · до четырёх вопросов

если удобнее выбрать имя, папку и стартовые материалы, запусти локальный установщик: macOS/Linux — `python3 install.py`, Windows PowerShell — `py install.py`. Python нужен только для этого способа. установщик не подключается к сети и не читает другие хранилища. он прекращает работу, если выбранная папка уже существует.

перед запуском можно сверить целостность из распакованной папки пакета: `python3 install.py --verify-only` или `py install.py --verify-only`. для ручной проверки см. `MANIFEST.sha256`.

обычное использование не требует Python, терминала, плагинов или ИИ. на телефоне распакуй архив вручную и открой папку `vault` в совместимом приложении Markdown; автоматическая мобильная установка отдельно не проверялась.

открытый комплект предназначен для отдельного использования как самостоятельная копия. если этот файл открыт внутри `SUTI.os`, базовый комплект уже собран. для более глубокой настройки есть отдельная подробная инструкция: [[_контуры/открытый/настройки/установка и настройка по глубине.md|установка и настройка по глубине]].

## после установки

открой свою новую папку как отдельное хранилище в Obsidian или редакторе Markdown. начни с [[начать.md]], затем продолжи [[_контуры/открытый/настройки/чек-лист настройки.md|чек-лист настройки]] только по необходимости. В командном режиме начни с [[сад/доступ и расширение.md|рабочего маршрута]].

проверить внешний пакет можно по [[_контуры/открытый/настройки/сделать хранилище своим.md|проверка перед передачей]]. для переноса личных данных сначала выбери конкретные файлы и просмотри план; массовый импорт не обязателен: [[_контуры/открытый/настройки/сделать хранилище своим.md]].

Obsidian устанавливается отдельно; сторонние плагины не требуются. тема и сниппет `vault/.obsidian/snippets/suti-os.css` включены заранее для этой чистой копии. в Obsidian открой «Настройки → Оформление → CSS-сниппеты», чтобы увидеть или отключить оформление. удаление сниппета не меняет заметки.

подробные технические настройки собраны в [[_контуры/открытый/настройки/установка и настройка по глубине.md|справочнике по установке]]. дополнительные уровни Plus и Pro описаны отдельно: [[сад/доступ и расширение.md]].

если хочешь добавить отдельный пакет, используй [[_контуры/открытый/настройки/добавить дополнение.md|инструкцию по установке без замены файлов]]. открытая основа, Plus и Pro — отдельные пакеты; не объединяй их через перезапись.
